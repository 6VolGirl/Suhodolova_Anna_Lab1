Лабораторная работа 1. Кто снизил активность и почему

Работа выполняется в Jupyter Notebook. Зависимости и версия Python описаны в `environment.yml`.

Цель — определить, у каких клиентов снизилась частота успешных оплат, описать характер снижения и сформировать воспроизводимые группы для кампании возврата активности. Данные синтетические и не описывают реальный банк.

## Требования

- Git
- Miniconda
- clients.csv и transactions.csv

## 1. Клонирование репозитория

```bash
git clone [https://github.com/6VolGirl/Suhodolova_Anna_Lab1.git](https://github.com/6VolGirl/Suhodolova_Anna_Lab1.git)
cd 6VolGirl/Suhodolova_Anna_Lab1
```

## 2. Создание окружения

Выполняется один раз:

```bash
conda env create -f environment.yml
conda activate ds-lab1
```

При следующих запусках достаточно активировать существующее окружение:

```bash
conda activate ds-lab1
```

## 3. Исходные данные

Перед запуском поместите файлы из задания в папку:

```text
data/raw/clients.csv
data/raw/transactions.csv
```

Исходные данные не хранятся в репозитории.
Рабочая папка при запуске — корень проекта.

## 4. Запуск ноутбука

Из корня проекта выполните:

```bash
jupyter lab
```

Откройте `01_analysis.ipynb`, выберите ядро окружения `ds-lab1` и выполните **Restart Kernel → Run All**.

После сохранения результатов анализа выполните `02_report.ipynb`. Он читает очищенные данные и строит итоговый отчёт.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `01_analysis.ipynb` | Аудит, очистка, исследование, метрики, гипотезы и отбор кампании |

## Описание исходных данных

### clients.csv — сведения о действующих клиентах на 30.06.2025

| Столбец | Описание |
|---|---|
| `client_id` | Идентификатор клиента |
| `birth_date` | Дата рождения |
| `gender` | Пол |
| `city` | Город проживания |
| `segment` | Сегмент клиента: Массовый, Зарплатный, Премиальный, Private |
| `loyalty_tier` | Уровень лояльности: Базовый, Серебро, Золото, Платина |
| `card_type` | Тип карты: Дебетовая, Кредитная, Премиальная |
| `registration_date` | Дата прихода клиента в банк |
| `card_open_date` | Дата открытия текущей карты |
| `income_source` | Источник зарплаты со слов клиента |
| `monthly_income` | Ежемесячный доход в рублях |
| `has_mobile_app` | Установлено ли мобильное приложение |
| `app_last_login` | Месяц последнего входа в приложение |
| `satisfaction_score` | Оценка качества обслуживания по опросу, от 1 до 5 |
| `branch_code` | Код отделения обслуживания |
| `marketing_opt_in` | Согласие на маркетинговую коммуникацию |

### transactions.csv — операции по картам

| Столбец | Описание |
|---|---|
| `txn_id` | Идентификатор операции |
| `client_id` | Идентификатор клиента |
| `txn_datetime` | Дата и время операции |
| `amount` | Сумма операции |
| `currency` | Валюта операции |
| `category` | Категория траты, одна из девяти |
| `mcc_code` | Код типа торговой точки, соответствует категории |
| `channel` | Способ оплаты: Карта — пластиковая карта; Токен — смартфон или часы через Pay-сервис; СБП — перевод по Системе быстрых платежей; Онлайн-банк — операция в интернет-банке |
| `status` | Статус операции: успешно, отклонено, возврат |

Описания приведены по заданию. Фактические значения и их соответствие описанию проверяются в `01_analysis.ipynb`.
